## 🧱 Daily Structure

Each interaction day ran 09:00–17:00 with a fixed rhythm — two lecture blocks, two lab blocks,
and a wrap-up checkpoint:

| Time | Block |
|------|-------|
| 09:00–10:30 | Morning Lecture I |
| 10:45–12:15 | Morning Lecture II |
| 13:15–15:15 | Afternoon Lab I |
| 15:30–16:45 | Afternoon Lab II |
| 16:45–17:00 | Wrap-up & Checkpoint |

Every day ends with a concrete deliverable (flag, script, or write-up) — tracked at the bottom
of each day's note under **Checkpoint / Deliverable**.
